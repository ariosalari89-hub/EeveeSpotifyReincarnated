# Synthetic audio fixture

`synthetic-tone.mp3` is a generated quarter-second 440 Hz sine wave, not a recording or user-provided song. It contains no personal audio. It is test-only and must never be included in an IPA.

Generation command (FFmpeg 7.1, libmp3lame):

```sh
ffmpeg -hide_banner -loglevel error -n -f lavfi \
  -i 'sine=frequency=440:sample_rate=44100:duration=0.25' \
  -codec:a libmp3lame -b:a 96k -metadata title='Synthetic local audio fixture' \
  synthetic-tone.mp3
```

Other PCM and AAC inputs are generated by the test with platform audio APIs in isolated temporary directories.
